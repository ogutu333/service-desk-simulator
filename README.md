# Service Desk Simulator

A hands-on IT service desk practice portfolio built using [ServiceDesk Simulator](https://servicedesk-simulator.com/).

This repository documents my practical experience working through simulated IT support tickets, from **ticket triage and investigation to troubleshooting, resolution, escalation, and technical documentation**.

Rather than only studying IT support concepts theoretically, I am using realistic service desk scenarios to practice how an entry-level IT support technician would approach problems in a workplace environment.

---

## Objectives

The goal of this lab is to develop practical experience in:

- Ticket triage and prioritization
- Troubleshooting and root-cause analysis
- Windows and endpoint support
- Network troubleshooting
- VPN and connectivity issues
- User and account administration
- Hardware troubleshooting
- Remote support
- Incident documentation
- Escalation and handoff
- End-user communication
- Security awareness

---

## Practice Platform

The tickets in this repository are completed using:

**ServiceDesk Simulator**

🔗 https://servicedesk-simulator.com/

The platform provides simulated IT support scenarios and tools that allow me to investigate and resolve workplace-style service desk issues.

This repository contains **my own notes, troubleshooting approaches, resolutions, lessons learned, and supporting evidence** from those exercises.

> **Note:** This repository does not contain or reproduce the ServiceDesk Simulator platform itself. It documents my individual practice and learning.
